# Archived Code-Web-Skills experiments

This directory absorbs the portable, reviewed experiment scripts and design notes that
previously lived on the private `DEM1TASSE/Code-Web-Skills` handoff branch.

It intentionally excludes raw trajectories, media, secrets, `.env` readers, hard-coded
deployment credentials, and early prototypes coupled to the retired gateway. Those private
artifacts remain only in the offline export bundle.

For runnable current code, use the repository root. Files under this directory are historical
evidence and design records, not a second implementation entry point.
